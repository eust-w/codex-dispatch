Title: Codex Dispatch: Real Codex CLI Task Queues | MIT Open Source Alpha

Codex Dispatch is a local-first queue console for the real Codex CLI.

Source and installation: https://github.com/eust-w/codex-dispatch

Organize projects, working directories and sessions. Tasks run FIFO within each session; different sessions can run in parallel. Prompts and execution results are persisted in SQLite. Optional Shadow Context injects bounded earlier task output; it is not native Codex Desktop chat synchronization.

Independent community alpha for macOS/Linux, Node.js 22+. Install and authenticate Codex CLI separately. Review local permissions before running prompts. Pending tasks survive restarts; interrupted tasks require inspection and an explicit retry. No exactly-once side-effect guarantee.
